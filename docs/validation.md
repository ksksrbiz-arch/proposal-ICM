# Validation scope

The kit passed documentation-link/schema checks and all 22 regression tests locally on Windows with Node22.23.4, Node24.22.2 and Node26.7.0, using installed Chrome through pinned Playwright. The Node22/24 portable runtimes were downloaded from the official Node distribution and checked against its SHA-256 manifest. The suite includes an actual all-route/six-viewport scan, real button outcome assertion, hashed evidence, independent-review contract, sealed-byte comparison, positive publication/registration contracts and negative private-path HTML fallback verification.

The fictional fixture is infrastructure test data. Its synthetic source, provider receipt, hosted-report contract and review scores are explicitly marked test-only; they are not evidence of a real deployment, actual design review or a premium business site. Future batches require actual source research, screenshot inspection, provider receipts, hosted behavior and live tracker readback.

Regression coverage includes: blank/no-authority packets, overwrite refusal, unresolved identity, unqualified factual claims, core-page parity and coverage, first-site eligibility, public allowlist/private files, traversal/symlinks, evidence hashes, stale source/test/output fingerprints, authority-only changes, builder/reviewer separation, batch collisions/overlap and leaky server fallbacks.

Recursive learning regressions cover unapproved drafts/unknown metrics, learning from a blocked delivery without marking it delivered, archived prior outcomes, independent/privacy review, distinct before/after evidence, rejection of fabricated promotion SHAs, contact-data rejection in public candidates and stage-routed adopted lessons. Test fixture reviews are synthetic contract tests, not evidence of a real agent's visual judgment.

GitHub Actions is configured for the same checks on Ubuntu/Node24 and Windows/Node22 with the pinned Playwright Chromium installation. The [initial workflow run](https://github.com/ksksrbiz-arch/proposal-ICM/actions/runs/41254746127) could not start either job because of an account-level runner restriction. No test steps ran there. Remote/Linux validation remains unverified until the account restriction is resolved and the workflow is run. Consult actual workflow results for current status.

Key implementation references: [Playwright emulation](https://playwright.dev/docs/emulation), [Playwright page API](https://playwright.dev/docs/api/class-page), [GitHub Node CI](https://docs.github.com/en/actions/tutorials/build-and-test-code/nodejs), [Ajv JSON Schema](https://ajv.js.org/json-schema.html). Dependency versions are pinned in package-lock.json; re-verify official docs and rerun tests when updating them.
