# Changelog

## 1.0.0 — 2026-10-31

Initial context router, eight stage contracts, root/worker/reviewer prompts, design standard, historical case-study lessons, private artifact schemas and batch isolation protocol. Added project initialization/state commands, fail-closed cross-artifact gates, all-route/six-viewport Playwright scanner, source/output fingerprints, reviewed-build seal and stable/immutable public verification. Regression fixtures exercise meaningful page parity, identity/facts, stale evidence, symlinks, allowlist leaks, self-approval and private-route HTML fallbacks. CI runs the checks on Linux/Node24 and Windows/Node22.

This release does not build or deploy real prospects, send outreach, migrate a tracker or change any site's pricing/domain. Those actions remain separately scoped for future batches. Visual quality and source correctness still require independent inspection; the toolkit does not guarantee subjective perfection.
