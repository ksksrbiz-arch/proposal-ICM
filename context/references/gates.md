# Gate codes

Generated by `npm run docs:gates` from `lib/gates/catalog.mjs`. Do not edit by hand; `npm run check` fails if it is stale. A gate prints every issue of the first failing stage as `[code] message`; `gate <project> all` shows every stage.

## brief

| Code | Meaning | Repair |
| --- | --- | --- |
| `brief.build-authority-missing` | No recorded user authority to build. | Record the actual user instruction and date in project.json permissions.build. Never invent it. |
| `brief.authority-record-incomplete` | A granted permission lacks a real instruction (12+ chars) or a valid date. | Quote the user instruction and an ISO date, or set granted:false. |
| `brief.reviewer-not-independent` | Builder and reviewer IDs are the same. | Assign a different root/reviewer ID. |
| `batch.invalid` | Batch manifest invalid, colliding or mismatched. | See docs/batch.md. |

## research

| Code | Meaning | Repair |
| --- | --- | --- |
| `research.identity-unresolved` | Business identity is not matched. | Match name plus phone/location from primary sources, record sources, then set identity.matched. |
| `research.duplicate` | Duplicate source/baseline/asset ID. | Make IDs unique. |
| `research.source-invalid` | A source has an unusable URL or checkedAt date. | Use an http(s) URL without credentials and an ISO date. |
| `research.source-unknown` | An identity/fact references a source ID that is not in sources[]. | Add the source or fix the ID. |
| `research.fact-unsupported` | A public fact has no source. | Attach source IDs or set publicUse:false. |
| `research.fact-unqualified` | A public INFERRED/VERIFY fact has no qualification text. | Write the qualification the site will show, or keep the fact private. |
| `research.baseline-url-invalid` | A checked baseline URL is invalid. | Use real http(s) URLs. |
| `research.baseline-no-core` | Known baseline has no accessible core page. | Inventory the real core pages or mark the baseline unknown. |
| `research.baseline-limitations-missing` | Unknown/absent baseline lacks limitations. | State what was checked and what blocked it (12+ chars). |
| `research.first-site-ineligible` | first-site scope needs checked-source proof that no company site exists. | Set baseline.status to no-company-site-found with evidence, or change scope. |
| `research.asset-source-invalid` | Asset source URL invalid. | Use the real source URL or original-generated. |
| `research.asset-uninspected` | An approved asset was never inspected. | Inspect the actual bytes, then set inspected:true. |
| `research.asset-identity-mismatch` | Approved photo is not tied to this business. | Confirm identity or exclude the asset. |
| `research.asset-changed` | Original asset bytes no longer match the recorded SHA-256. | Restore the original or re-inspect and re-record it. |

## design

| Code | Meaning | Repair |
| --- | --- | --- |
| `design.concept-review-missing` | Root has not reviewed the concept. | Root reviews the concept and sets conceptReviewedBy to the reviewer ID. |
| `design.duplicate` | Duplicate route path or flow ID. | Make them unique. |
| `design.route-invalid` | A route path is malformed. | Use a clean absolute path without query, hash, backslash or trailing slash. |
| `design.route-action-dead` | A primary action target is empty, # or javascript:. | Point it at a real destination. |
| `design.route-source-unknown` | A route cites an unknown source. | Fix the source ID. |
| `design.route-asset-unapproved` | A route uses an unapproved or unknown asset. | Approve the asset in assets.json or remove it. |
| `design.route-baseline-unknown` | A route claims coverage of an unknown baseline page. | Fix baselineIds. |
| `design.homepage-missing` | No "/" route. | Add the homepage route. |
| `design.parity-count` | Fewer meaningful core pages than the existing site. | Add substantive core pages. Details/utility pages do not count. |
| `design.parity-uncovered` | An existing core page is not covered by a new core route. | Cover it through baselineIds on a core route. |
| `design.flow-entry-unknown` | A flow starts at an unplanned route. | Fix the entry route. |
| `design.flow-handoff-invalid` | External handoff destination is not a URL/tel/mailto/sms. | Use a real destination. |
| `batch.similar-design` | Two projects in a wave share a near-identical layout signature. | Rework one concept; do not reskin a skeleton. |

## build

| Code | Meaning | Repair |
| --- | --- | --- |
| `build.allowlist-mismatch` | Public directory differs from the allowlist. | List exactly the files in outputDir, and remove extras. |
| `build.private-file-public` | A private/source/record file is in the public output. | Move it outside outputDir and the allowlist. |
| `build.config-only-unsupported` | Unsupported config-only file. | Only _headers and _redirects may be config-only and must be allowlisted. |
| `build.release-files-missing` | Custom 404, robots.txt or deployment.json missing. | Add all three to the output and allowlist. |
| `build.robots-open` | robots.txt does not disallow everything. | Add "User-agent: *" and "Disallow: /". |
| `build.marker-mismatch` | deployment.json does not match projectId/buildStamp. | Regenerate the marker from the build. |
| `build.placeholder-content` | Placeholder or unfinished text is in a public page. | Replace lorem ipsum/TODO/TBD/coming-soon text with real authored content. |
| `build.claim-unsupported` | A price, phone, email, year, rating or superlative has no matching public research fact. | Add a sourced publicUse fact containing the exact value, or remove the claim. |
| `build.html-structure` | Basic document structure is missing (lang, title, viewport, alt). | Fix the HTML in the build source. |
| `build.link-unsafe` | A link is dead (#, empty, javascript:), malformed tel/mailto, or opens a new tab without noopener. | Give it a real target and rel="noopener". |
| `build.mixed-content` | A page loads an http:// subresource. | Use https or remove it. |

## qa

| Code | Meaning | Repair |
| --- | --- | --- |
| `qa.stale` | qa.json fingerprint does not match current inputs. | Re-run browser-qa and flow tests after the last change. |
| `qa.technical` | Technical report is stale, wrong mode, failing, duplicated or incomplete. | Re-run browser-qa and fix reported failures. |
| `qa.screenshot-invalid` | A screenshot is missing, not a PNG or the wrong size. | Regenerate with browser-qa. |
| `qa.flow-failed` | A planned flow is untested or its evidence reports failure. | Run the flow test and record a passing, real report. |
| `qa.defect-open` | Open critical/high defect, or a defect without disposition. | Fix it, or record a concrete disposition for medium/low. |

## review

| Code | Meaning | Repair |
| --- | --- | --- |
| `review.stale` | review.json is stale or the reviewer is not independent. | Re-review the current build as a different person. |
| `review.coverage` | A route lacks mobile+desktop screenshot review tied to the QA screenshots. | Review every route and reference the exact hashed screenshots. |
| `review.score` | Review scores are below 4 each or 26 total. | Return to the owning stage and improve; never adjust scores to pass. |

## publish

| Code | Meaning | Repair |
| --- | --- | --- |
| `publish.not-authorized` | No recorded publication authority. | Record the user instruction and date. |
| `publish.seal` | Seal is stale, missing a file, or a sealed file changed. | Re-review and run seal again; never rebuild after sealing. |
| `publish.provider` | Provider record, URLs, stamp or receipt are not valid. | Record real provider evidence with two distinct HTTPS origins. |
| `publish.hosted` | Hosted QA or public verification is missing, stale or wrong. | Run browser-qa hosted and verify-public against the same fingerprint. |
