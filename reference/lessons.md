# Lessons from the first proposal waves

These are historical design/process studies, not live business facts. Re-research each company before reuse. Preview URLs demonstrate proposals, not official approval. No business photos, contact records, pricing sheets or private research are copied into this repo.

| Study | What became stronger | Reusable lesson |
| --- | --- | --- |
| [Neanderthals](https://neanderthals-concept.pages.dev/) | Expanded from a single page to real booking, safety, league, line dancing, calendar, menu and contact pages; retained existing scheduling provider and mascot | Audit the complete current navigation before estimating scope. Preserve familiar identity and working systems. |
| [L.A. Landscaping](https://la-landscaping-concept.pages.dev/) | Original before/after compositions, full-image access and references tied to actual project inquiries | Design around evidence of the work; don't invent separate project stories from several views of one property. |
| [Saba's](https://sabas-alterations-concept.pages.dev/) | Complete bridal garment framing, differentiated bridal/everyday paths, authentic portfolio and private-fitting process | A fashion service needs garment detail and trust, not an auto-repair card layout in new colors. |
| [King Kaiden](https://king-kaiden-concept.pages.dev/) | Actual tattoo work, piece-specific browsing, mobile-studio details and preserved booking/shop paths | Detail routes serve portfolio navigation but do not inflate core-page parity. Expanded preview scope must be reconciled with the quote. |
| [Raven](https://raven-hair-concept.pages.dev/) | Original color-work photography, stylist context and existing appointment handoff | Make inspiration useful and preserve the booking provider rather than inventing a new scheduler. |
| [Blue Star](https://blue-star-battleground-concept.pages.dev/) | Actual counter photography, garment-service navigation and clear shop visits | Service identity can be modest and specific; a huge generic hero is not premium. |
| [Los Toritos](https://toritos-battleground-concept.pages.dev/) | Real food/truck imagery, menu/phone paths and useful visit details | Food should lead; confirm current location/menu rather than amplifying conflicting directories. |
| [Pet Spa NW](https://pet-spa-nw-concept.pages.dev/) | Authentic grooming portraits, practical first-visit information and direct appointment call | A genuine small photo set is stronger than fake staff/customer results. |
| [Claudia's](https://claudias-la-center-concept.pages.dev/) | Genuine salon exterior, warm type-led pages and explicitly labeled illustration studies | Sparse authentic assets require honest art direction and owner-photo launch inputs. |
| [Mountain View Farm](https://mountain-view-farm-concept.pages.dev/) | Flower/produce/market paths and a sourced farm story | Seasonal dates and market attendance need time-aware qualification; a listing is not current inventory. |
| [Tillie's](https://tillies-acres-concept.pages.dev/) | Original stand/seasonal compositions and a clear visit checklist | An archival “closed” sign is not permission to claim currently open; avoid publishing residential location assumptions. |

Recurring failures to prevent at the front of the process: one-page scope when the existing site has multiple real pages; repeated homepage skeletons; oversized dead space; small phone copy; homepage-only QA; generic note tools dominating every business; inaccessible complete images; guessed contact/booking claims; publication inferred from a build; historical README dates overriding current markers; tracker updates erasing human notes.

Our prior responsive runs and byte-verification scripts informed this kit. They are proof for their historical builds only. The kit's scanner and regression tests must validate each new project; never copy an old passing report or screenshot into a new lead's packet.
